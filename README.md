# Advanced Fabrics API

Canonical machine-readable contracts for Advanced Fabrics:

- `openapi/observation-v1.yaml`: read-only Observation API.
- `schemas/config-v1.schema.json`: portable `config.advfab.org/v1` configuration.
- `proto/provider/v1/provider.proto`: replaceable provider protocol.

Generated SDKs must record the exact API commit and must not introduce consumer-specific semantics.
